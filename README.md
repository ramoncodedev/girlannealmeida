# Psicóloga Girlanne Almeida — Link bio

Página de link bio de [@psigirlannealmeida](https://www.instagram.com/psigirlannealmeida/).

```
index.html      estrutura (HTML)
css/style.css   estilos (mobile first, desktop ≥ 960px)
js/main.js      faixas animadas, aparição ao rolar, ano do rodapé
```

Site estático: basta abrir o `index.html` ou publicar a pasta em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).
